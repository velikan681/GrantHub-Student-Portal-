# GrantHub Student Portal

## 1. Название проекта
GrantHub Student Portal - веб-портал грантовых возможностей для обучающихся вузов.

## 2. Цель проекта
Разработать современную систему, которая помогает студентам находить гранты, стипендии, конкурсы, стажировки и обменные образовательные программы, сохранять интересные предложения и подавать заявки с документами.

## 3. Используемые технологии
- Backend: Python 3.11, Django 5
- Frontend: HTML, CSS, JavaScript, Bootstrap 5
- Database: SQLite
- Excel export: openpyxl
- Authentication: встроенная система Django с кастомной моделью пользователя
- Admin panel: Django Admin и отдельная web-панель проекта

## 4. Функциональные возможности
- Регистрация, авторизация, восстановление пароля и редактирование профиля.
- Роли: студент, администратор, представитель организации или вуза.
- Каталог грантов с поиском и фильтрами по стране, направлению, уровню образования, дедлайну и типу возможности.
- Детальная страница гранта с требованиями, документами, официальной ссылкой, сохранением и подачей заявки.
- Личный кабинет студента: профиль, сохраненные гранты, заявки, статусы, рекомендации и уведомления.
- Загрузка документов для заявки: CV, мотивационное письмо, сертификаты.
- Административная панель: управление грантами, пользователями, категориями и заявками.
- Кабинет представителя организации: добавление своих программ и просмотр заявок на них.
- Подробная панель управления для администратора и организации: статистика, фильтры заявок, популярные программы, разрезы по категориям и странам.
- Excel-выгрузка `.xlsx`: администратор получает полный отчет, представитель организации - отчет только по своим программам и заявкам.
- Rule-based рекомендации на основе уровня образования и интересов студента.
- Уведомления о дедлайнах, новых подходящих грантах и изменениях статуса заявки.
- JSON-маршруты `/api/grants/`, `/api/profile/`, `/api/my-applications/`, `/api/saved-grants/`, `/api/recommendations/`, `/api/notifications/`.

## 5. Структура проекта
```text
GrantHub Student Portal/
├── config/                 # настройки Django-проекта
├── portal/
│   ├── management/commands/ # команда seed_demo
│   ├── static/portal/       # CSS и JavaScript
│   ├── templates/portal/    # HTML-шаблоны
│   ├── admin.py             # регистрация моделей в Django Admin
│   ├── forms.py             # формы регистрации, профиля, грантов и заявок
│   ├── managers.py          # менеджер кастомного пользователя
│   ├── models.py            # модели базы данных
│   ├── services.py          # рекомендации и уведомления
│   ├── urls.py              # маршруты приложения
│   └── views.py             # контроллеры страниц и API
├── media/                   # загружаемые документы заявок
├── manage.py
├── requirements.txt
└── README.md
```

## 6. Инструкция по установке
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 7. Инструкция по запуску
```bash
python manage.py makemigrations
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

После запуска откройте `http://127.0.0.1:8000/`.

Запуск тестов:
```bash
python manage.py test portal
```

## Запуск через EXE
Для Windows подготовлен лаунчер:

```text
dist\GrantHubStudentPortal\GrantHubStudentPortal.exe
```

Запустите `GrantHubStudentPortal.exe`. Он автоматически:
- подготовит SQLite-базу;
- добавит демо-данные, если база пустая;
- запустит локальный сервер;
- откроет портал в браузере.

Если порт `8000` занят, приложение выберет следующий свободный порт. Для переноса на другой компьютер используйте всю папку `dist\GrantHubStudentPortal` или архив `GrantHubStudentPortal-Windows.zip`.

Пересборка EXE:
```powershell
powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
```

Демонстрационные аккаунты:
- Администратор: `admin@granthub.local` / `admin12345`
- Представитель организации: `partner@granthub.local` / `partner12345`
- Студент: `student@granthub.local` / `student12345`

## 8. Описание ролей пользователей
- Студент: просматривает каталог, фильтрует гранты, сохраняет предложения, подает заявки, получает рекомендации и уведомления.
- Администратор: управляет пользователями, грантами, категориями и всеми заявками.
- Представитель организации или вуза: добавляет грантовые программы, редактирует только свои программы и просматривает заявки на них.

## 9. Описание базы данных
- Users: ФИО, email, пароль, роль, университет, факультет, курс, уровень образования, интересы.
- Grants: название, описание, организатор, страна, категория, тип возможности, уровень образования, требования, документы, дедлайн, ссылка, автор, дата создания.
- Applications: студент, грант, CV, мотивационное письмо, сертификаты, статус, дата подачи.
- SavedGrants: связь студента и сохраненного гранта.
- Notifications: пользователь, сообщение, признак прочтения, дата создания.
- Categories: направления и категории грантов.
